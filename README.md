## About

具志堅裕介がp5.js で作成したWebアプリケーションの集約リポジトリです。  
A collection of web applications created by Yusuke Gushiken


## アプリ一覧
- [01: テ〜ブル万華鏡](https://yusukegushiken-coder.github.io/94-apps/01_Tabel_Kaleid/)

WEBカメラを使って、身の回りのものでカレイドパターンを作成して遊ぶWEBアプリケーションです。  
This is a web application that uses your webcam to create kaleidoscope patterns from objects around you.


- [02: ピクソニフアシッドデジタルイメージ](https://yusukegushiken-coder.github.io/94-apps/02_pixonif_ACID_Digital_Image/)

画像ファイルを使ってアシッド・サウンドを鳴らすWEBアプリケーションです。  
This is a web application that lets you play acid sounds using digital image files.
