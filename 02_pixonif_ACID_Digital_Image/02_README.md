## ピクセルデータとサウンドの対応仕様（Color-to-Sound Mapping）

**PIXONIF ACID Digital Image** は、サンプリング円上の16ステップ（12時方向から時計回り）の各ピクセルから **HSB（色相・彩度・明度）** を抽出し、シンセサイザーとドラムマシンをリアルタイムに制御します。

---

### 1. SYNTH（アシッド・シンセサイザー）

#### 色相（Hue: 0° 〜 360°）→ ピッチ（音高・周波数）
色相 `0° 〜 360°` を **15°刻み（全24半音＝2オクターブ）** に分割し、`F1`（約 43.6 Hz）〜 `E3`（約 164.6 Hz）のベース音階にマッピングします。

| 色相（Hue） | 色の目安 | 音名 | 周波数 (Hz) |
| :--- | :--- | :--- | :--- |
| **0° 〜 14°** | 赤 | **F1** | 43.6 Hz |
| **15° 〜 29°** | 赤橙 | **F#1 / Gb1** | 46.2 Hz |
| **30° 〜 44°** | 橙 | **G1** | 49.0 Hz |
| **45° 〜 59°** | 黄橙 | **G#1 / Ab1** | 51.9 Hz |
| **60° 〜 74°** | 黄 | **A1** | 55.0 Hz |
| **75° 〜 89°** | 黄緑 | **A#1 / Bb1** | 58.3 Hz |
| **90° 〜 104°** | 緑 | **B1** | 61.7 Hz |
| **105° 〜 119°** | 緑 | **C2** | 65.3 Hz |
| **120° 〜 134°** | 青緑 | **C#2 / Db2** | 69.2 Hz |
| **135° 〜 149°** | シアン | **D2** | 73.3 Hz |
| **150° 〜 164°** | 青緑 | **D#2 / Eb2** | 77.7 Hz |
| **165° 〜 179°** | 水色 | **E2** | 82.3 Hz |
| **180° 〜 194°** | 青 | **F2** | 87.2 Hz |
| **195° 〜 209°** | 青 | **F#2 / Gb2** | 92.4 Hz |
| **210° 〜 224°** | 深青 | **G2** | 97.9 Hz |

| **270° 〜 284°** | 赤紫 | **B2** | 123.3 Hz |
| **285° 〜 299°** | マゼンタ | **C3** | 130.7 Hz |
| **300° 〜 314°** | マゼンタ | **C#3 / Db3** | 138.4 Hz |
| **315° 〜 329°** | ピンク | **D3** | 146.7 Hz |

#### 明度・彩度 → フィルター＆エンベロープ制御

| パラメータ | 入力範囲 | 変化する音響要素 | 変化の範囲・挙動 |
| :--- | :--- | :--- | :--- |
| **明度（Brightness）** | `0% 〜 100%` | **Filter Cutoff（カットオフ周波数）** | **80 Hz 〜 2000 Hz**（暗いほど重厚な低音、明るいほど鋭い音色） |
| **彩度（Saturation）** | `0% 〜 100%` | **Env Mod（フィルター跳ね上がり幅）** | **0 〜 6 オクターブ**（鮮やかな色ほどうねるアシッド感が増加） |
| **彩度（Saturation）** | `0% 〜 100%` | **Synth Gain（出力音量）** | **0% 〜 50%**（無彩色・彩度 0% 付近は発音なし） |

### 2. BEATS（ドラムマシン：TR-909 / TR-808）

#### 明度（Brightness: 0% 〜 100%）の絶対値によるトリガー
各ステップのピクセルの明るさに応じて、対応するドラムパーツが発音します。

| 明度（Brightness） | 明るさの目安 | ドラムパーツ | 出力音量 |
| :--- | :--- | :--- | :--- |
| **0% 〜 15.0%** | 黒・極めて暗い | **BD**（バスドラム / キック） | 70% |
| **15.1% 〜 20.0%** | 暗い | *（休符・発音なし）* | - |
| **20.1% 〜 25.0%** | やや暗い | **LT**（ロータム） | 40% |
| **25.1% 〜 30.0%** | やや暗い | **MT**（ミドルタム） | 40% |
| **30.1% 〜 35.0%** | やや暗い | **HT**（ハイタム） | 40% |
| **35.1% 〜 70.0%** | 中間〜やや明るい | *（休符・発音なし）* | - |
| **70.1% 〜 80.0%** | 明るい | **RC**（ライドシンバル） | 40% |
| **80.1% 〜 90.0%** | かなり明るい | **CH**（クローズド・ハイハット） | 50% |
| **90.1% 〜 100%** | 白・極めて明るい | **OH**（オープン・ハイハット） | 40% |

#### 明度の変化量（前ステップとの差分）によるトリガー
隣り合うステップ間の明度差（コントラストの境界）を検知して発音します。

| 条件（明度の変化量） | 視覚的な変化 | ドラムパーツ | 出力音量 |
| :--- | :--- | :--- | :--- |
| **+20.0% より大きく上昇** | 暗い場所 → 明るい場所への境界 | **SD**（スネアドラム） | 20% |
| **-20.0% より大きく下降** | 明るい場所 → 暗い場所への境界 | **HC**（ハンドクラップ） | 35% |

#### オプション機能
- **AUTO KICK**：ON にすると、画像の明度に関わらず 4つ打ち位置（ステップ `0, 4, 8, 12`）で **BD（100%）** を自動発音します（`BEATS` が OFF の状態でも単独で動作します）。
